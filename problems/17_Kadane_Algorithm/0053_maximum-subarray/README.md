## 1. 题目大意与核心考点

- **一句话题意**：给你一个整数数组 `nums` ，请你找出一个具有最大和的**连续子数组**（子数组最少包含一个元素），返回其最大和。
- **约束条件**：
  - $1 \le nums.length \le 10^5$
  - $-10^4 \le nums[i] \le 10^4$
  - 数组可能包含正数、负数或**全为负数**（极值边界！）。
- **核心考点**：连续子数组的贪心选择性、前缀和断舍离机制、Kadane 算法、全负数边界初始化。

## 3. 错因深层剖析与三大认知飞跃

### 飞跃一：死循环（TLE）的结构性病因
在提交 01 和 02 中：
```cpp
while ( p < nums.size() ){
    left_sum += nums[p];
    if (left_sum < 0) {
        left_sum = 0;
        p++; // ❌ 致命错误：p++ 只有在和小于 0 时才走！
    }
    // ...
}
```
- **后果**：如果遇到一个正数（比如第 1 个数是 `5`），`left_sum = 5 >= 0`，不进 `if`，`p` 永远是 0！`while` 陷入死循环，力扣直接报 `Time Limit Exceeded`。
- **最佳实践**：凡是数组遍历，**无条件使用 `for (int i = 0; i < n; ++i)` 或 `for (int x : nums)`**，把循环变量的自增交给循环头，绝对不让分支语句干扰指针推进。

---

### 飞跃二：“0 不是万能最小值”——全负数边界大坑
在提交 03 中：
```cpp
int max = 0; // ❌ 极度危险的初值！
```
- **踩坑用例**：`nums = [-1]` 或 `nums = [-3, -2, -5]`。
- **为什么挂了**：
  题目要求“子数组最少包含一个元素”。在全负数数组中，最大的和必定是负数（例如 `-1`）。如果初值设为 `0`，算法最后输出的全局最大值只能是 `0`，而原数组里根本就不存在能加出 `0` 的子数组！
- **防御法则**：
  在求最大值的题目中，只要元素可能为负数，初始值必须设为：
  1. `INT_MIN`（头文件 `<climits>`）；或
  2. 首个元素 `nums[0]`。

---

### 飞跃三：Kadane 算法的心智模型——“断舍离”
你在第 4 次提交中改写出来的结构，正是世界著名的 **Kadane 算法（卡丹算法）**：
```cpp
if (left_sum < 0) {
    left_sum = 0; // 之前的累计和已经是负数了，带上它只会成为后续的拖累，果断断舍离清零！
}
left_sum += nums[p]; // 从当前元素重新起航
if (left_sum > max) {
    max = left_sum;
}
```
- **核心哲学**：子数组必须连续。对于当前元素 `nums[p]`：
  - 如果前面的累加和 `left_sum > 0`，那对我当前元素是有增益的，我选择“加入团队”；
  - 如果前面的累加和 `left_sum <= 0`，说明前面的团队是负资产，加进来只会让我变小，我选择“自立门户”（从我开始重新算起）。

## 4. 标杆最优解

- **代码文件**：[solution.cpp](solution.cpp)

```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int cur_sum = 0;
        int max_sum = nums[0]; // 直接用第一个元素初始化，优雅免疫全负数

        for (int x : nums) {
            // 如果前面累加和是负资产，清零（自立门户）
            if (cur_sum < 0) {
                cur_sum = 0;
            }
            cur_sum += x;
            max_sum = max(max_sum, cur_sum);
        }

        return max_sum;
    }
};
```

### 复杂度分析
- **时间复杂度**：$O(N)$，一次线性遍历，击败 100%。
- **空间复杂度**：$O(1)$，两个整型状态变量，完美原地计算。
