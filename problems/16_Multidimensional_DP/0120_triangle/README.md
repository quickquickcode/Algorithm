## 3. 思维破局：自顶向下 vs 自底向上的降维打击

### 为什么选择“自底向上（Bottom-up）”是神来之笔？
1. **自顶向下的痛点**：
   从第一行往下走，到达底层时会有 $N$ 个落脚点，最后必须再做一次全局遍历 $\min(dp[n-1][0 \dots n-1])$ 来求最小值；并且每一层的两端元素只有一条来源路径，需要写大量的边界判断。
2. **自底向上的优雅收敛**：
   - 最后一层的所有点本身就是天然的初始状态，无需初始化。
   - 从倒数第二层往上走，每个节点只需在正下方和右下方挑选较小者累加：
     $$dp[i][j] = \text{triangle}[i][j] + \min(dp[i+1][j], dp[i+1][j+1])$$
   - **天然收敛于一个点**：当循环结束时，`triangle[0][0]` 自动就是整个三角形的全局最优解！
   - 原地在 `triangle` 上累加，额外空间为严格的 **$O(1)$**，时空效率直接双双登顶（100% / 97.9%）。

## 4. 标杆最优解

- **代码文件**：[solution.cpp](solution.cpp)

```cpp
class Solution {
public:
    int minimumTotal(vector<vector<int>>& triangle) {
        int depth = triangle.size();
        for (int i = depth - 2; i >= 0; i--) {
            for (int j = 0; j <= i; j++) {
                triangle[i][j] += min(triangle[i + 1][j], triangle[i + 1][j + 1]);
            }
        }
        return triangle[0][0];
    }
};
```
