## 1. 题目大意与约束

- **一句话题意**：$n$ 个孩子站成一排，每个孩子有评分。每个孩子至少分配 1 颗糖果；相邻两个孩子中评分更高的必须获得更多的糖果。求分发糖果的最少总数。
- **核心契约与边界**：
  - 基础保底：每个孩子至少 1 颗糖。
  - 相邻评分严格递增/递减时必须分级递增；若评分相等（`ratings[i] == ratings[i-1]`），则没有严格多分的约束，只需保底 1 颗即可。
  - 这是一个典型的**双向局部偏序约束问题**，必须同时满足左邻居与右邻居的相对大小要求。

## 2. 真实思维卡点与困境（为什么第一直觉想不到？）

### 1. 直觉陷阱：试图在单次遍历中“同时兼顾左右”
- **思维困局**：直觉上，很多人会尝试一次循环从左向右遍历，既想让当前孩子比左边多，又想让他比右边多。
- **致命矛盾（无法预知未来的下坡）**：
  以评分 `[1, 3, 5, 4, 3, 2, 1]` 为例：
  当走到评分 `5` 时，为了满足比左边的 `3` 更多，直觉上可能给它 `3` 颗糖。但后续紧跟着长达 4 个元素的连续递减！
  根据规则，后面的 `[4, 3, 2, 1]` 最少必须分别拿 `[4, 3, 2, 1]` 颗糖；为了比右边的 `4` 还要多，位于峰顶的 `5` 必须至少拿到 **5 颗糖**！
- **结论**：**站在峰顶时，从左向右根本无法预知右边坡度有多深**。单向同时顾及两端必然导致回溯修补或逻辑死结。

## 3. 认知跃迁：双向解耦与两次贪心（Aha Moment）

### 核心突破：将双向强约束拆解为两个独立的单向弱约束
这道题之所以被奉为 Hard 级别的贪心典范，其精髓在于**维度解耦**：

1. **左规则（只要比左边高，就比左边多 1 颗）**：
   - 若 `ratings[i] > ratings[i - 1]`，则 `candies[i] = candies[i - 1] + 1`；
   - 否则只需保底给 `1` 颗。
   - 从左向右线性扫描一次即可 100% 满足左规则。

2. **右规则（只要比右边高，就比右边多 1 颗）**：
   - 若 `ratings[i] > ratings[i + 1]`，则 `candies[i] = candies[i + 1] + 1`；
   - 否则只需保底给 `1` 颗。
   - 从右向左线性扫描一次即可 100% 满足右规则。

3. **全局最优的数学本质：取两者的最大值 $\max$**：
   - 一个孩子若要**同时满足左规则和右规则**，他所拥有的糖果数必须同时大于等于左规则给出的建议值和右规则给出的建议值：
     $$\text{candies}[i] = \max(\text{left}[i], \text{right}[i])$$
   - 取较大值既满足了更严格的那一侧要求，又天然覆盖了较宽松的那一侧要求，且保证了分配的糖果数全局最小！

## 4. 标杆题解

### 解法 A：双向两次扫描法（最直观、最好写、零心智负担）
- **代码文件**：[solution.cpp](solution.cpp)
- **算法流程**：
  1. 初始化长度为 $n$ 的数组 `candies`，初值全为 1；
  2. 从左往右遍历（$1 \to n-1$），落实左规则：若 `ratings[i] > ratings[i-1]`，则 `candies[i] = candies[i-1] + 1`；
  3. 从右往左遍历（$n-2 \to 0$），落实右规则：若 `ratings[i] > ratings[i+1]`，则 `candies[i] = max(candies[i], candies[i+1] + 1)`；
  4. 累加 `candies` 元素和即为最终答案。

```cpp
class Solution {
public:
    int candy(vector<int>& ratings) {
        int n = ratings.size();
        if (n <= 1) return n;

        vector<int> candies(n, 1);

        // 1. 满足左规则：比左边高就比左边多
        for (int i = 1; i < n; i++) {
            if (ratings[i] > ratings[i - 1]) {
                candies[i] = candies[i - 1] + 1;
            }
        }

        // 2. 满足右规则：比右边高就比右边多，取 max 原地融合
        for (int i = n - 2; i >= 0; i--) {
            if (ratings[i] > ratings[i + 1]) {
                candies[i] = max(candies[i], candies[i + 1] + 1);
            }
        }

        // 3. 统计总数
        return accumulate(candies.begin(), candies.end(), 0);
    }
};
```
- **复杂度**：时间复杂度 $O(N)$（两次线性扫描），空间复杂度 $O(N)$。
