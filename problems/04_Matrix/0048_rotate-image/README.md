## 3. 几何分解法：如何将复杂的旋转拆解为简单的对称？

很多刚接触二维矩阵旋转的同学，会试图去推导“四角循环交换”的公式（$(i, j) \rightarrow (j, n-1-i) \rightarrow \dots$），极易写出死循环或覆盖。

而你使用的**几何分解法（Reflection Decomposition）**是线性代数中最精妙的直觉：

$$\text{顺时针旋转 } 90^\circ = \text{沿主对角线转置} + \text{沿垂直中轴线水平翻转}$$

```
[原始矩阵]          [1. 对角线转置 (i, j) <=> (j, i)]      [2. 水平翻转 (i, j) <=> (i, n-1-j)]
1  2  3              1  4  7                               7  4  1
4  5  6   ───────>   2  5  8                 ───────>      8  5  2
7  8  9              3  6  9                               9  6  3
```

### 致命的 Off-by-one 细节纠偏
在提交 01 中引发错误的根源：
```cpp
matrix[i][j] = matrix[i][l - j]; // ❌ 错！C++ 下标从 0 到 l-1
```
- 当 $j = 0$ 时，`l - 0 = l`，直接访问了数组第 $l$ 列（越界或踩中内存野值）！
- **对称轴公式铁律**：长度为 $L$ 的数组中，下标 $j$ 的对称位置永远是 **`L - 1 - j`**。

## 4. 标杆最优解

- **代码文件**：[solution.cpp](solution.cpp)

```cpp
class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        int n = matrix.size();

        // 1. 转置矩阵（对角线右上三角与左下三角互换）
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                swap(matrix[i][j], matrix[j][i]);
            }
        }

        // 2. 左右镜像翻转（只翻前 n/2 列）
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n / 2; j++) {
                swap(matrix[i][j], matrix[i][n - 1 - j]);
            }
        }
    }
};
```

### 复杂度分析
- **时间复杂度**：$O(N^2)$，转置遍历 $N(N-1)/2$ 次，翻转遍历 $N^2/2$ 次，两遍常数极小，0ms 击败 100%。
- **空间复杂度**：$O(1)$，纯原地两次交换，没有任何辅助矩阵。
