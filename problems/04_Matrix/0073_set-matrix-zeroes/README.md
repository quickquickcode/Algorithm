## 3. 深度诊断：为什么 47 ms 仅击败 5.05%？哪些地方可以进化？

### 漏洞 1：未去重导致的“重复重刷”（严重拖慢常数）
你当前使用的方案：
```cpp
if (matrix[i][j] == 0) {
    list_i.push_back(i);
    list_j.push_back(j);
}
```
- 如果第 0 行有 50 个 0，那么 `list_i` 里就会塞入 50 个 `0`。
- 后续在置零循环中，第 0 行被反复刷新清零了 50 遍！
- 当矩阵中 0 很多时，时间复杂度急剧退化为 $O(M^2 N + M N^2)$，这就是 **47 ms** 的根本原因。

### 漏洞 2：动态 `vector` 的堆内存分配开销
`vector<int> list_i` 在频繁 `push_back` 时会触发多次动态扩容和内存重新分配，使得内存占用飙升至 21.8 MB（仅击败 5.11%）。

### 终极思维跃迁：如何达成 $O(1)$ 常数额外空间？
1. 我们需要记录“哪一行、哪一列该清零”，本质上需要 $M$ 个行标记和 $N$ 个列标记。
2. **既然原矩阵不能使用额外数组，那能不能借用矩阵自身的第一行和第一列来充当“标记黑名单”？**
   - 如果 `matrix[i][j] == 0`，就给它所在的表头打标记：
     - `matrix[i][0] = 0`（告知第 $i$ 行要清零）
     - `matrix[0][j] = 0`（告知第 $j$ 列要清零）
3. **唯一的冲突点在 `matrix[0][0]`**：
   - 第一行和第一列在左上角重叠了！
   - 解决方案：用两个独立的布尔变量 `first_row_zero` 和 `first_col_zero` 记录首行首列自己原本是否有 0。
   - 内部元素全处理完之后，最后再根据这两个布尔值刷新首行和首列。

## 5. 标杆最优解（0 ms 击败 100%）

- **完整代码见**：[solution.cpp](solution.cpp)

```cpp
class Solution {
public:
    void setZeroes(vector<vector<int>>& matrix) {
        int m = matrix.size(), n = matrix[0].size();
        bool row0 = false, col0 = false;

        // 1. 检查第 0 行原本是否有 0
        for (int j = 0; j < n; j++) {
            if (matrix[0][j] == 0) { row0 = true; break; }
        }

        // 2. 检查第 0 列原本是否有 0
        for (int i = 0; i < m; i++) {
            if (matrix[i][0] == 0) { col0 = true; break; }
        }

        // 3. 复用首行和首列作为标记位
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                if (matrix[i][j] == 0) {
                    matrix[i][0] = 0;
                    matrix[0][j] = 0;
                }
            }
        }

        // 4. 利用首行首列的标记将内层元素置零
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                if (matrix[i][0] == 0 || matrix[0][j] == 0) {
                    matrix[i][j] = 0;
                }
            }
        }

        // 5. 单独刷新首行
        if (row0) {
            for (int j = 0; j < n; j++) matrix[0][j] = 0;
        }

        // 6. 单独刷新首列
        if (col0) {
            for (int i = 0; i < m; i++) matrix[i][0] = 0;
        }
    }
};
```
