## 1. 题目大意与接口特征

- **一句话题意**：以数组 `intervals` 表示若干个区间的集合，其中单个区间为 `intervals[i] = [start_i, end_i]`。请你合并所有重叠的区间，并返回一个不重叠的区间数组。
- **关键接口特征**：
  ```cpp
  vector<vector<int>> merge(vector<vector<int>>& intervals)
  ```
  - **返回值是一个全新的 `vector<vector<int>>`**！
  - 题目**没有要求必须原地修改输入数组**，你可以自由使用新的容器。

## 3. 为什么思考了这么久？三大思维误区解剖

### 误区一：沉锚效应（Anchoring Effect）——画地为牢的“原地强迫症”
仔细看你每一版代码的第一行：
```cpp
vector<vector<int>> v{}; // 声明了 v，但整整 15 次提交，你一次都没用过它！
```
- **错因深层心理**：因为前几道题（27 题、26 题、80 题）都在反复强调“原地修改”，你在潜意识里形成了一个**思维枷锁**：以为这道题也必须原地把重叠区间 `erase` 掉！
- **真相反思**：本题签名是 `vector<vector<int>> merge(...)`，要求返回一个新数组。你明明申请了 `v`，却不敢把合并好的区间 `push_back` 进去，反而逼着自己在原数组里顶着巨大的索引偏移做极其危险的 `erase()`。

---

### 误区二：在混沌无序中打打杀杀（没有排序）
输入给你的区间是完全无序的，例如 `[[2,6], [15,18], [1,3], [8,10]]`。
- 如果不排序，任何一个区间都可能和数组里任意另一个未知位置的区间重叠。
- 你被迫写出了双层嵌套循环 `while(i) { while(j) }`，时间复杂度先天沦为 $O(N^2)$。
- 两个任意区间的几何相对位置极其复杂（A在B左边？A在B右边？A包含B？B包含A？部分相交？），这就是为什么你花了十几次提交去调试 `(b>=c && c>=a) | (d>=a && a>=c)` 这种令人头晕目眩的四元不等式！

---

### 误区三：容器边遍历边 `erase()` 的地狱模式
在 `while(i < size)` 循环中调用 `intervals.erase(begin + i)`：
1. 每次 `erase` 都会导致底层内存向左大搬迁（单次 $O(N)$，全流程退化为 $O(N^3)$ 级别开销）；
2. 导致你的运行时间飙升到了 **2075 ms**（差点超时被卡死）。

## 4. 为什么你想不到题解的优解？（认知的缺失环节）

题解的思路极其简单，只有两步：
1. **先按左端点排序**：`sort(intervals.begin(), intervals.end());`
2. **拿个新容器像“传送带”一样单遍扫描**。

### 为什么你第一反应想不到“排序”？
> **关键认知缺失：缺乏“用排序消灭一个维度的自由度（降维打击）”的解题直觉。**

- 一个区间有两个端点：$[start, end]$，自由度是 2（二维变化）。
- **一旦按照左端点 `start` 升序排序，左端点的混乱度瞬间归零（降为一维）！**
  因为对于后来的区间 `curr` 和前面的区间 `prev`，**`curr[0] >= prev[0]` 已经是一个绝对成立的真理！**
- 你再也不需要考虑复杂的“相交方向”：
  你只需要看一眼：**后一个人的左脚，有没有踩进前一个人的右脚里？**
  - **踩进去了**（`curr[0] <= prev[1]`） $\rightarrow$ 必然重叠！直接把前一个人的右脚拉长：`prev[1] = max(prev[1], curr[1])`；
  - **没踩进去**（`curr[0] > prev[1]`） $\rightarrow$ 绝对不可能重叠！作为崭新的独立区间放进答案中。

## 5. 标杆最优解（15 ms 极简代码）

- **代码文件**：[solution.cpp](solution.cpp)

```cpp
class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        if (intervals.empty()) return {};

        // 1. 降维打击：按区间左端点升序排列
        sort(intervals.begin(), intervals.end());

        vector<vector<int>> merged;

        // 2. 流式传送带收集
        for (const auto& interval : intervals) {
            // 如果是第一个区间，或者和上一个区间没有交集，直接入库
            if (merged.empty() || merged.back()[1] < interval[0]) {
                merged.push_back(interval);
            } else {
                // 有交集：直接扩充上一个区间的右端点
                merged.back()[1] = max(merged.back()[1], interval[1]);
            }
        }

        return merged;
    }
};
```

### 复杂度对比
| 指标 | 你的双层循环暴力+erase | 题解（排序 + 贪心扫描） |
| :--- | :---: | :---: |
| **时间复杂度** | $O(N^2)$ ~ $O(N^3)$ | **$O(N \log N)$**（耗时全在快排） |
| **实际运行耗时** | **2075 ms** | **15 ms**（快了 138 倍！） |
| **代码逻辑行数** | 35 行（充满容易写错的逻辑嵌套） | **10 行**（清晰直白，零边界隐患） |
