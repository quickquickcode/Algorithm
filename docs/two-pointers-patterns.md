# 双指针核心模式体系与循环不变量

> 双指针（Two Pointers）是数组与链表面试中最常见也最容易在边界细节上翻车的算法思想。本篇建立三种核心指针模式的心智模型。

---

## 模式一：逆向 / 倒序双指针（Backward Two Pointers）

### 典型代表：LeetCode 88. 合并两个有序数组

### 核心痛点与启发
- **正向操作的问题**：若从头开始合并，`nums1` 前面的原始元素会被立刻覆盖，必须借助 $O(M+N)$ 的辅助数组或执行 $O(N)$ 的 `insert`。
- **空间观察**：`nums1` 的后半部分全为无用占位空间（`0`）。
- **破局思路**：**从后往前填**！比较两数组当前最大值，谁大谁去最末尾的槽位。

### 循环条件与残余处理哲学
- 指针初始化：
  - `p1 = m - 1`（`nums1` 有效末尾）
  - `p2 = n - 1`（`nums2` 末尾）
  - `tail = m + n - 1`（写入指针）
- 为什么只需要 `while (p2 >= 0)`？
  - 当 `p2 < 0` 时，说明 `nums2` 的所有元素都已归位。
  - 此时 `nums1` 若还有剩余元素（`p1 >= 0`），它们本来就在 `nums1` 的最前方，且本身已经有序，**不需要再做任何移动**！

## 模式二：快慢双指针（Fast-Slow Pointers）

### 典型代表：LeetCode 27. 移除元素、LeetCode 26. 删除有序数组中的重复项

### 核心思想
- **角色分配**：
  - **快指针 `fast`**：探路者。负责无条件向前遍历每一个元素。
  - **慢指针 `slow`**：守门员。指向下一个合法元素应该写入的位置，同时维护当前有效数组的长度。
- **循环不变量（Loop Invariant）**：
  - 在区间 `[0, slow)` 内的所有元素都是被保留的合法元素。

### 模板代码
```cpp
int slow = 0;
for (int fast = 0; fast < nums.size(); ++fast) {
    if (nums[fast] != val) {
        nums[slow] = nums[fast];
        slow++;
    }
}
return slow; // slow 即为新数组长度
```

### 为什么快慢指针是首选？
1. **绝对安全**：`for` 循环由 `fast` 控制，完全杜绝了死循环与下标越界风险。
2. **逻辑纯粹**：不需要考虑复杂的边界碰撞，只做“过滤与收集”。

## 模式三：对撞 / 双向对向双指针（Collision Two Pointers）

### 典型代表：LeetCode 27（优化版）、LeetCode 167. 两数之和 II

### 核心思想
- 两个指针从两端向中间靠拢（`left = 0, right = n - 1`）。
- **适用场景**：当元素顺序可以被打乱，且目标元素较少时，直接把右侧不需要删除的元素**覆盖**到左侧待删除的位置。

### 经典避坑点：内层 `while` 越界
在写对撞指针时，初学者极易写出如下危险代码：
```cpp
// ❌ 极度危险：内层 while 无边界检查
while (left < right) {
    while (nums[left] != val) left++; // 越界风险！
    while (nums[right] == val) right--; // 下溢风险！
    ...
}
```
- **越界场景**：若数组中所有元素均不等于 `val`，`left` 会一直自增直到越界；若数组全部为 `val`，`right` 会一直自减到 `-1`。
- **准则**：**任何 `while` 循环对数组下标做自增/自减，都必须强制加上范围限制**（如 `left < nums.size()` 和 `right >= 0`）。

### 推荐的覆盖式对撞写法
```cpp
int left = 0, right = nums.size() - 1;
while (left <= right) {
    if (nums[left] == val) {
        nums[left] = nums[right]; // 将右侧元素移到当前位置
        right--;                   // 右侧指针左移
        // 注意：此时 left 不能++，因为移过来的 nums[right] 仍可能等于 val
    } else {
        left++;                    // 当前位置合法，检查下一个
    }
}
return left;
```
- 优势：写操作次数最小（如果只需删除极少数元素，这种方法避免了快慢指针的大量原地自我复制）。
